# 需求条目（L1）

- 渲染管线描述及其阶段子项与官方逐字段同名同形在场（含每阶段编译选项子项）。
  **验收**：官方管线构建例片段按字段名初始化对本层词汇书写，编译通过。
- 着色器源词汇形制与官方一致：WGSL 单串形态（借用载体）、GLSL 按阶段单源、版本由源码自身承载。
  **验收**：官方 WGSL/GLSL 两种构造式均编译通过；原「两段合一 + 外置版本槽」构造式退役。
- 管线布局描述在场官方「推送范围」字段及其载体词汇，逐字段一致。
  **验收**：空范围创建与现行为等价；非空范围=创建失败短码；与能力位恒 false、上限恒 0 的查询面对表成立。
- 管线布局允许缺省：缺位=违约（断言含 label、短码），不半建管线。
  **验收**：缺省路径在约定短码处失败；带布局路径行为不变。
- 多视角、管线缓存两槽位词汇在场：给值=违约短码，缺省=现行为。
  **验收**：违约断言消息含错误码；缺省路径回归通过。
- examples 三例全部适配新形态且行为等价。
  **验收**：cargo build 通过；hello_triangle 可见+稳定回归（pi-wgpu-rebuild 基线）；textured_quad 正常绘制。
- 公开面无旧形态残留。
  **验收**：全仓检索，旧构造式与旧字段名零公开引用。
