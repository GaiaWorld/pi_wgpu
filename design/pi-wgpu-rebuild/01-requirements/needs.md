# pi-wgpu-rebuild · 需求（L1）

## 需求（L5 门禁校准版：资产管理两行出库，共 17 条）

### 一套渲染代码三平台同形编译运行
- 描述：同一份上层代码可在 Windows 桌面、浏览器、Android 编译运行。
- 验收：Given triangle/hello/clear 样例，When 分别按 Win 与浏览器（wasm）链路运行，Then 画面符合基线；Android 编译链就绪（真机验收延后）。
- 来源：documents FR-01/03/04/05 + 对话拍板（验收环境轮2）。

### 对外是 wgpu-rs 25.x 兼容子集，对象与描述符同名同形
- 描述：上层按官方接口形态编码，本库实现其子集。
- 验收：Given 兼容子集内的官方实现上层代码，When 依赖换成本库，Then 不改代码可编译运行。
- 来源：documents FR-01 + 轮2 基线拍板。

### 内置实现与参考实现一键切换对照
- 描述：编译开关整面切到官方 wgpu-rs（参考实现），A/B 排差（即「整库切换」）。
- 验收：同一份样例在开关两种取值下均可编译运行、画面可对拍。
- 来源：documents FR-02。

### 渲染能力子集：单颜色目标 + 可选深度模板
- 描述：清空/载入、混合/深度/模板/剔除、视口裁剪（wgpu 坐标约定）、索引与非索引绘制、离屏渲染目标。
- 验收：Given render_target 用例，When 离屏渲染并合成上屏，Then 与参考实现一致。
- 来源：documents FR-06。

### 绑定按 set/binding 声明、支持动态偏移，上限写死
- 描述：set 仅 0–3，UBO/采样器/顶点属性各 ≤16 槽；越界即崩并给清晰标签。
- 验收：gui_demo 高频动态偏移 UBO 正常渲染；越界用例触发带标签崩溃。
- 来源：documents FR-07 + 轮2 写死拍板。

### 着色器源接受 WGSL 与 GLSL，自动转译并自动登记绑定
- 描述：转成各形态可编译的统一输出，(set,binding)↔名字/位置的映射无需手工指定。
- 验收：triangle 的 WGSL 在 Win/浏览器渲染正确（绑定名自动定位）。
- 来源：documents FR-08。

### 纹理格式表 + Mipmap 自动生成 + 压缩纹理直载（DDS/ASTC）
- 验收：image、compress_texture 以测试模式跑通。
- 来源：documents FR-09。

### 录制即执行：提交/收尾空壳，写入即时生效
- 描述：命令录制=立即执行；上层不得依赖提交前校验/回滚。
- 验收：同帧写入后立即绘制生效；无提交前错误回滚承诺。
- 来源：documents FR-13 + 轮1 拍板沿用。

### 资源创建/销毁可跨线程（上下文附着搬运）
- 描述：本库保证非录制线程创建/销毁安全（锁+附着搬运）；单线程合同下零开销退化。
- 验收：多资源反复装卸压力用例，跨线程创建销毁无崩溃。
- 来源：documents FR-12 + 轮1 拍板线程面保留库内。

### 资源删除时机确定：即删 + 状态镜像同刷失
- 描述：对象 drop 即调 driver 删、镜像同步作废（无延迟队列兜底）；被复用类对象（程序/顶点属性/离屏附件）待全部持有者释放后删。
- 验收：删后重建同配置对象功能正常、画面无残影；镜像刷失可由日志/抓帧验证（无冗余重绑指令）。
- 来源：L5 门禁校准拍板（2026-10-13），替代旧「统一记账+延迟回收」条目中库内部分。

### 下发驱动指令数不劣于参考实现同场景
- 描述：靠全状态镜像差异下发 + 管线级与离屏附件对象复用；纹理/缓冲/采样器一律 1:1 直建（wgpu 独立对象语义）。
- 验收：浏览器抓帧计数 ≤ use_wgpu 同样例。
- 来源：documents FR-11 + L5 复用范围拍板。

### 呈现约束：配置仅两种合法组合，取帧含错误态，一帧一次呈现
- 描述：present 模式仅顺序队列、alpha 仅不透明；取当前帧可失败（超时/过期/丢失/显存不足）；重复呈现即崩。
- 验收：帧循环在 Win/浏览器稳定；重复 present 触发断言。
- 来源：documents FR-14。

### 已知问题驱动的特判规避有登记
- 验收：特判登记表逐项可查；无对应设备时降级为「代码点位收口 + 清单」。
- 来源：documents FR-16（一手平台约束=待验证，见 notes）。

### 可诊断：全量调用 trace 日志 + 浏览器端 GL 错误探针 + debug 默认验证标志
- 验收：黑屏/掉帧场景可凭日志离线重建调用序列，无需断点。

- 描述：draw 之后、渲染通道结束后、与绑定组同弃——库不校验、即删；违约后果=画面错误或未定义，文档写明。
- 验收：违约路径不承诺行为；文档含三条规则与反例。
- 来源：轮1 拍板 + L5 校准（即删后合同硬度升级）。
