# pi-wgpu-rebuild · 模块（L5 · 资产出库校准版）

## 模块清单（实现 12 个，按易变决定切；原 13 中 reclaim 撤销——回收机制出本库。types 词汇面另计：模块图节点=12+1）

| 模块 | 职责 | 隐藏的易变决定（恰一） |
|---|---|---|
| types | 对外接口词汇面：描述符/枚举/位标志/Limits/常量/纹理格式表（纯数据） | 词汇表跟 wgpu 25.x 对表与裁剪（上游版本演进） |
| entry | 公开对象面：Instance/Adapter/Device/Queue/Encoder 对象、调用即转发、对象持有引用链 | 公开对象面合同形态（「错误面=三处结果值其余断言」与「引用链=对象强持有」是同一决定的两面：对象面失败/持有合同） |
| surface | 窗口/画布附着、呈现配置校验、取帧、交换（suboptimal 恒真语义沿用旧实现，登差异清单） | 呈现约束（Fifo+Opaque 唯一合法、一帧一次、配置前置） |
| context | 驱动上下文获取与搬运、重入锁、single_thread 退化 | 线程合同（哪些操作可离录制线程、锁与搬运策略） |
| caps | 适配器能力探测、features/limits 回报、已知问题驱动特判；debug 构建 VALIDATION 标志归属 | 特判集合（iOS18/Qualcomm 等，新增只动这里） |
| state | 驱动状态镜像与「差异才下发」 | 镜像字段集与比较粒度（性能决策） |
| objects | GL 句柄统一面：纹理/缓冲/采样器 1:1 直建；程序/VAO/FBO/RBO 按配置键复用；drop 即删+通知镜像刷失；上下文代号失效校验 | 释放规则（同一决定的两面：键怎么算＋归零何时删——刷失是即删配套非独立决定） |
| formats | 格式→驱动参数转换、纹理创建管道（mipmap 生成、DDS/ASTC 直载） | 格式支持集与转换表（新增格式动这里） |
| binds | 绑定槽分配：(set,binding)→UBO/采样器全局槽、管线 reorder、动态偏移消耗 | 槽位分配/重排规则（16 槽上限、复用重合） |
| shader | 着色器桥：转译（WGSL/GLSL→GLSL ES 3.0 统一输出）、编译链接、反射登记 | 转译输出形态与反射契约（绑定 naga fork） |
| draw | 渲染通道录制：FBO 边界/clear-load-store、绑定应用、视口翻换、VAO 属性批 | 通道能力约束（单颜色目标、pass 边界=Drop 语义、参数级限制） |
| upload | 数据写路径：缓冲/纹理写入即时生效、对齐换算、JS 图像直传（wasm 扩展面） | 写入生效时机（即时下发 vs 未来改提交栅栏） |
| utils | 便捷构造（Buffer/Texture init）、env 助手、锁包装、调用 trace 单点（公开入口包装，编译开关控制出入日志） | 附加便利面（是否扩项） |

## 非显然的切分理由

| 模块 | 为什么这样切 | 为什么不能更简单 |
|---|---|---|
| objects（复用边界：四类键复用、三类 1:1） | 复用=性能决定（FR-11 加分项），1:1=wgpu 独立对象语义决定（业务复用是资产层的键值缓存职责）——两决定各归其位 | 全键复用会把「同描述符 texture 互相干扰」的语义分歧留给上层；全不复用则 program/VAO 重建大头实测存在（消费者=gui_demo 高频换管线） |
| upload 独立 | 写时机是独立语义决定（轮1 拍板即时生效），不该被 objects 缓存策略吞掉 | 并入 objects 则同一模块藏复用键+生效时机两决定，元判据违例 |
| draw 与 state 分离 | 通道能力约束（单目标/Drop 边界）与镜像字段的性能决策是两种变化方向 | 合一则任何性能调参都要动通道语义 |
| reclaim 撤销 | 删除时机=即删后无队列，机制归 context/objects 的代号校验 | 曾按 documents FR-10 设自研模块——L5 校准判「资产管理出本库」（变更日志留痕） |
| utils→entry 单向 | 便捷面消费公开对象面（trait 扩展 DeviceExt）；lib 伞面 re-export 是 entry 的导出表，不记调用边，防 utils/entry 成环 | re-export 画实线成假环，环检失败 |

## 资源账本 · GL 句柄的进库面（⑦ 校准版：进库/不进库与删除方式）

| 资源 | 方式 | 删除 | 记账 | 镜像刷失 |
|---|---|---|---|---|
| 纹理/缓冲/采样器 | 1:1 直建、不键复用（wgpu 独立对象语义） | drop 即调驱动删 | 不在本库（上游资产层） | 即刷 |
| 程序/顶点属性对象/帧缓冲/渲染缓冲 | 键=转译产物哈希/属性布局/附件组合（仅本库四种复用） | 全部持有者释放后删（引用规则 L7 定） | 同上 | 重绑走差异下发 |
| 默认帧缓冲 | 不建对象 | — | — | — |
| EGL/上下文/窗口/canvas | 随 surface/context 对象生死 | 对象面 drop | — | lost=上下文代号+1 整面刷失（objects 校验点） |
| 纹理视图/布局表等值结构 | 纯值（types/entry 内部数据） | 随宿主 | — | — |
| 业务资产（URL 键/异步/容量收缩） | **出本库**——上游资产 crate 在本库公开 API 上自建 | — | — | — |
